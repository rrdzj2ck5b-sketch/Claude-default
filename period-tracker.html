How to import from Clue:
  1. Open Clue → Settings → Request data
  2. Copy the password shown on screen — you’ll need it to unzip
  3. Check your email for the download link and save the ZIP
  4. Unzip the file using the password and select measurements.json below
Mac users: the built-in unzip doesn’t support Clue’s encryption. Use The Unarchiver (free on the Mac App Store) — right-click the ZIP → Open With → The Unarchiver, then enter the password.
